Scattering Multiplicities

These are my notes on multiplicity in scattering experiments, I found the construction quite intuitive at first, but as I thought about it more I realised there are quite a few subtle points essential to the argument that no one really talk about - I highlight them below. Again, I don't actually know if this is the right way of looking at things, and there are possibly issues with the argument. And the page could really use some pictures.

Geometrical Intuition

Suppose I send a X-ray beam into a solid crystal with wavevector $\vec{\bf{k}} \propto \vec{\bf{x}}$. Under most situations, there will be no scattering. To get scattering, we have to rotate the crystal around such that we find an orientation that satisfies Laue's condition. This raises the following question: how do we specify the orientation of our crystal in space?

Imagine that we paint tiny arrows representing the "normal axis" of the crystal. Then, the orientation of the crystal can be described by first specifying the orientation of this normal axis in space, followed by a clockwise rotation angle of the crystal about this normal axis. The former requires two angles, while the latter requires one angle, so in total three angles are needed.

Now, say we fix $\vec{\bf{k}} \propto \vec{\bf{x}}$ and start rotating the crystal. When will Laue's condition be satisfied? One can think of this geometrically in terms of a construction known as Ewald's sphere. Imagine the reciprocal space. In the reciprocal space, draw a sphere centered at $\vec{\bf{k}}$ which touches the origin. The surface of this sphere describes the set of all possible reciprocal space points $\vec{\bf{k}} - \vec{\bf{k}}'$ can access for different $\vec{\bf{k}}'$s with $|\vec{\bf{k}}| = |\vec{\bf{k}}'|$. Now, with the sphere pivoted at the origin, rotate the sphere around in reciprocal space. In general, the surface of the sphere will not intersect any reciprocal lattice points $\vec{\bf{G}}$, since the reciprocal lattice points are, well, points. However, for a "discrete" set of orientations the sphere will intersect reciprocal lattice points - these are the orientations for which scattering occurs. I put quotation marks around discrete because the orientations are not truly discrete - once we find a case where there is an intersection, we can rotate the Ewald sphere to generate an infinite set of similar intersecting orientations; this is because the Ewald sphere also has three independent parameters, two for its normal direction and one for rotations about that normal, and although the third rotation leaves the sphere unchanged it will change the deflection angle of the X-ray in real space (is this right?).

In the above picture we rotate the Ewald sphere - this corresponds to changing the direction of the incoming X-rays while keeping the crystal orientation fixed. Alternatively, we can also keep the direction of the incoming X-rays fixed and rotate the crystal. In fact, we can simply smash the crystal into a powder, so that we get a sample containing all possible crystal orientations.

Naturally, the question we should ask is: how will the crystal orientations be distributed in this powder sample? Intuitively, one will expect an isotropic distribution of normal directions ($\frac{1}{4\pi}$) and an uniform distribution of rotation angles ($\frac{1}{2\pi}$) about any axis (it is obvious that this holds for the normal axis, but there is nothing special about the normal axis; we could have chosen the normal axis to be any axis and still expect an uniform distribution of rotation angles about it). In the reciprocal space picture this corresponds to fixing the Ewald sphere and rotating the crystal lattice around.

Now, we want to count the number of crystal orientations that give scattering in a certain direction. The scattering direction in this case is given by $\cos \theta = \hat{\bf{k}}\cdot\hat{\bf{k}}'$. Because $\hat{\bf{k}}$ is fixed, all reciprocal lattice points $\vec{\bf{G}}$ that scatter at a given $\theta$ must have the same length $|\vec{\bf{G}}|$. In addition, we note that because the reciprocal lattice sites are sharp points, the length $|\vec{\bf{G}}|$ has no effect on the intersection probability of $\vec{\bf{G}}$ (even though intuitively a larger $|\vec{\bf{G}}|$ appears to imply a larger solid angle and therefore higher probability of intersecting the Ewald sphere).

We can work out the geometry systematically as follows. First, consider just the slice of the Ewald sphere in the x-z plane (here the x axis points right, y axis points into the screen and z axis points up). In this plane the Ewald sphere is really an Ewald circle. The probability of intersection between any given reciprocal lattice point and the "Ewald circle" is the same across all accessible reciprocal lattice points, due to the aforementioned independence of $|\vec{\bf{G}}|$. Therefore, the probability of a given scattering angle $\theta = \arccos (\hat{\bf{k}}\cdot\hat{\bf{k}}')$ is proportional to the number of reciprocal lattice vectors with length $|\vec{\bf{G}}| = |\vec{\bf{k}} - \vec{\bf{k}}'|$. If we look only at intersections on our "Ewald circle", then $|\vec{\bf{G}}|, \vec{\bf{k}}, \vec{\bf{k}}'$ all lie in the x-z plane, and the scattered light will all lie along the z axis of the detector screen. Now, we note that we are actually dealing with Ewald's sphere - so we need to consider all intersections with the sphere and not just a slice of it. But the extension to this is easy, because as we have noted above, the distribution of rotation angles about any axis is uniform. So once we have a crystal orientation that intersects the Ewald sphere in the x-z plane, we can further rotate the crystal about the x-axis to generate a continuous set of intersecting orientations. Importantly, the additional factor introduced by this rotation is the same across all points. Therefore, this additional rotational degree of freedom in counting will not change the ratio of intersection probabilities between different $\vec{\bf{G}}$s. One thing does change however: for any given $\vec{\bf{G}}$ the scattered light now forms a ring of uniform intensity. This is because the plane spanned by $\vec{\bf{G}}$ and $\vec{\bf{k}}$, and therefore the plane in which $\vec{\bf{k}}'$ lies in, rotates. Additionally, we should note that in general there will be a discrete set of $\vec{\bf{G}}$s that all scatter to give rings with the same scattering angle $\theta$; these are the $\vec{\bf{G}}$ that have the same length $|\vec{\bf{G}}|$. This means that we expect the intensities of the scattered rings to vary across different scattering angles $\theta$. This intensity is proportional to the size of the set $\{ \vec{\bf{G}}; \text{equal } |\vec{\bf{G}}| \}$. The quantity $|\{ \vec{\bf{G}}; \text{equal } |\vec{\bf{G}}| \}|$ is called the multiplicity of the corresponding scattering direction.

Now let's do an example. Consider scattering due to the reciprocal lattice vector with Miller indices $(3, 1, 1)$; under a suitable choice of $|\vec{\bf{k}}|$ this scattering produces a ring of uniform intensity at the scattering angle $\theta_{3, 1, 1}$. How many other reciprocal lattice vectors also contribute to scattering in the direction $\theta_{3, 1, 1}$? As we have said above, the answer is to simply count the number of $\vec{\bf{G}}$s with the same length, in this case $\sqrt{1^2 + 1^2 + 3^2} = \sqrt{11}$. This can be done by computing $m_p$, the number of unique permutations of the indices $(3, 1, 1)$ and $m_s$, the number of permutations of the signs $(\pm, \pm, \pm)$.

In this case, $m_p = 3$: $(3, 1, 1), (1, 3, 1), (1, 1, 3)$, and $m_s = 2^3 = 8$ since none of the Miller indices are $0$. Therefore, the multiplicity $m(3, 1, 1) = m_p \cdot m_s = 24$.
